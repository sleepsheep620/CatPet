# 小猫桌宠 🐱

**年糕**（橘猫）和**多比**（长毛虎斑）的桌宠，用真实照片做的。
启动时随机出现其中一只。

---

## 怎么用（两种方式，选一个）

### 方式一：直接运行（最快，推荐先试这个）

1. 双击 **`run.bat`**
2. 首次运行会自动装 Pillow（几秒钟）
3. 小猫出现，完成

> 需要电脑上有 Python。没有的话看方式二里的安装说明。

### 方式二：打包成 exe（发给朋友用）

1. 双击 **`build.bat`**
2. 等 1~3 分钟
3. 得到 `dist\CatPet.exe` —— 这个文件**发给任何人双击就能用，对方不需要装 Python**

**如果提示找不到 Python**：
- 去 https://www.python.org/downloads/ 下载安装
- ⚠️ 安装时**一定要勾选 "Add Python to PATH"**（在安装界面最下方）
- 装完**重启命令行**再试

## 怎么玩

| 操作 | 效果 |
|---|---|
| **左键单击** | 切换到下一张照片 |
| **双击** | 冒爱心 + 随机说话（台词看它心情） |
| **按住拖动、快速甩出** | 把猫扔出去！会飞出去、落地弹两下 |
| **右键 → 给它一条小鱼干** | 掉出一条鱼，**拖到猫身上**就吃掉 |
| **右键 → ⏰ 日程提醒** | 设置定时提醒（自带每小时喝水提醒） |
| **右键 → 开机自启动** | 开机后小猫自动出现 |
| **右键 → 跟着鼠标** | 开关：猫会横着跟着鼠标走 |
| **不管它** | 静止；但会慢慢变饿，饿了会抱怨 |

## 养成系统 🍚

- **饱腹度 0~100**，每 90 秒掉 1 点（约 2.5 小时从满到空）
- 饿了（<40%）会主动说「饿了」「猫粮呢？」；快饿死（<12%）会说「救命」
- **关机也在饿**：存档保存在 `~/.catpet_state.json`，隔天打开它已经饿着等你了
- 右键菜单随时显示当前饱腹度

## 日程提醒 ⏰

右键 → **⏰ 日程提醒**。首次使用自带一条「**喝水（每 1 小时）**」。

- 到点的提醒会以**蓝色气泡**弹出，停留 6 秒，猫还会换个表情、冒颗爱心
- **打开设置…** 可以：
  - 添加提醒，三种类型：
    - `每隔 N 分钟`（如 60 = 每小时喝水）
    - `每天 HH:MM`（如 22:30 该睡了）
    - `仅一次`：指定**具体日期 + 时间**（如 `2026-11-15` `14:30`），到点只提醒这一次，适合交房租、体检这类一次性的事
  - 启用/停用/删除任何一条；双击列表条目也能快速开关
  - 暂停全部 / 恢复喝水提醒
- 设置窗口右上角**实时显示当前系统时间**，添加成功会告诉你「今天 / 明天 / 5 天后」
- 一次性提醒触发后自动标记「已完成」；时间已过的会拒绝添加，防止手滑
- 提醒设置**随存档保存**，重启后依然生效；关机错过的提醒开机后会补一条
- 多个提醒同时到点会排队依次弹，不会互相覆盖

## 开机自启动 🚀

右键 → **开机自启动**（打勾 = 开启）。

- 原理：写入注册表 `HKCU\...\CurrentVersion\Run`，只对当前用户生效，不需要管理员权限
- 用 `build.bat` 打包的 exe：自启动直接指向 exe
- 用 `run.bat` 运行的：自启动指向 `pythonw.exe catpet.py`（无黑色命令行窗口）
- 再次点击即可取消自启动

## 台词风格

淘气吐槽风，按饱腹度分组：
- **饱**：「朕吃饱了」「嗝～」「这鱼干还行」
- **正常**：「喵」「求撸」「你又在摸鱼？」
- **饿**：「人，饭呢」「就这？」
- **快饿死**：「救命」「我恨你（小声）」
- **被甩飞**：「哇啊——」「我还会回来的」

## 分享给朋友 🎁

**推荐：只发一个 exe 文件**

1. 你自己电脑上先双击 `build.bat` 打包，得到 `dist\CatPet.exe`（带猫脸图标）
2. 把 `CatPet.exe` 单独发给朋友（微信 / QQ / 网盘都行，约 20~30MB）
3. 朋友双击就能用，**对方不需要装 Python、不需要装任何东西**

**朋友第一次打开要注意**：
- Windows 可能弹蓝色警告「Windows 已保护你的电脑」——点 **更多信息 → 仍要运行**
- 原因：exe 没有数字签名（买签名要花钱），微软不认识它，不是病毒
- 发送时可以直接把 `发给朋友的话.txt` 里的内容复制过去

**注意事项**：
- 朋友那边有自己独立的存档（饱腹度、提醒设置互不影响）
- exe 是按你电脑的 Windows 打包的（64 位）；朋友若是极老的 32 位系统会打不开
- 想换素材再分享：改完 `assets` 后重新跑一次 `build.bat`

**朋友用 iPhone？不，电脑是苹果 Mac（macOS）的话**：
- exe 只能在 Windows 上跑，Mac 朋友要把**整个 `catpet` 文件夹**发过去
- 朋友双击 `run_mac.command` 即可运行（首次需装 Python，脚本会引导）
- **朋友不想装 Python？** 看 `Mac版_不装Python的打包办法.md`：用 GitHub 免费的 Mac 机器（浏览器点几下）或借一台 Mac 打一次包，
  产出 `CatPet.app`，朋友双击即用、什么都不用装
- 想给 Mac 朋友发一个独立 App：在**任意一台 Mac 上**双击 `build_mac.command`，得到 `dist/CatPet.app`
- **打包的 App 一打开就闪退（Tcl_Panic / TkpInit）？** 这是 Mac 自带 Python 的图形库是坏的，PyInstaller 把坏库打了进去。修复：从 [python.org](https://www.python.org/downloads/) 安装官方 Python，删掉 `dist` 后重新打包。两个脚本现在都会自动检测这个问题并引导
- Mac 上被 Gatekeeper 拦的话：右键 → 「打开」→「打开」
- Mac 版功能一致（透明、置顶、喂食、提醒都有）；「开机自启动」菜单在 Mac 上会显示为不可用（注册表是 Windows 的）

## 换素材

`assets` 下每个文件夹就是一只猫，**启动时随机出现其中一只**。

### 命名规则

```
assets/niangao/idle_0.png      ← 待机
assets/niangao/idle_1.png      ← 待机（交替播放）
assets/niangao/walk_0.png      ← 走路（可选）
assets/niangao/rest_0.png      ← 趴窝休息
assets/niangao/stretch_0.png   ← 伸懒腰
assets/niangao/happy_0.png     ← 被摸头时的表情
```

- 动作名：`idle` / `walk` / `rest` / `stretch` / `happy` / `blink`，也可以自定义
- 三个必须的：`idle`、`happy` 建议要有；`walk` 没有就不走动

### 出场概率

角色文件夹里放 `weight.txt`，写个数字（默认 1，写 2 就是两倍概率）：

```
2
```

### 换完素材

- 用 `run.bat` 运行的：**直接重启就行**，不用重新打包
- 用 exe 的：重新跑一次 `build.bat`

## 常见问题

**Q：双击 bat 出现一堆乱码？**
A：旧版本的脚本有这个问题，现在的 `build.bat` / `run.bat` 是纯英文，不会乱码。如果还遇到，右键 bat → 编辑，确认文件没被记事本改成 GBK 编码。

**Q：exe 打开被杀毒软件拦了？**
A：PyInstaller 打包的 exe 没有数字签名，容易被误报。点「仍要运行」即可。发给朋友时可以提一句。

**Q：小猫不出现 / 一闪而过？**
A：用命令行跑 `python catpet.py` 看报错信息。常见原因是没装 Pillow：`pip install pillow`
